# 注意力水母

一个本地优先的 Chrome 扩展，把用户在网页版小红书上的注意力流向转化成一只安静的小水母和一份仅保留 7 天的私人报告。

## 当前能力

- 在小红书网页右上角显示“小澜”动态水母
- 以颜色、漂浮幅度、动作节奏和表情映射主题多样度、切换频率和浏览强度
- 初次出现或鼠标靠近时挥手；平静浏览时缓慢漂浮；主题切换较多时动作更活跃；打开轨迹面板时进入回顾表情
- 按停留、展开、视频、点赞、收藏、评论等信号记录有效浏览
- 本地保存文章标题、正文、标签、主题与浏览行为
- 点击水母查看最近 15 分钟轨迹
- 日报、周报、文章搜索和主题纠正
- 7 天后自动彻底删除文章与对话数据
- 本地 AI 适配层；未安装模型时使用可解释的本地检索回答

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `attention-jellyfish`。
5. 打开网页版小红书并刷新页面。

修改扩展文件后，需要先在 `chrome://extensions/` 中点击扩展卡片上的“重新加载”，再刷新已经打开的小红书标签页；仅刷新小红书页面可能继续使用旧的内容脚本。

## 隐私

浏览记录、搜索问题与生成结果默认只保存在浏览器本地。记录在 7 天后删除。清除浏览器扩展数据或卸载扩展也会清除本地记录。

## 开发状态

这是 v0.2 MVP。水母使用通过 v2 宠物规范验证的 8×11 动作精灵图，包含 9 组标准动作与 16 个视线方向。小红书页面结构会变化，内容提取器采用多组选择器与文本回退策略，后续需要在真实页面中持续校准。
